# Binary to Decimal

This program converts a binary number into its decimal equivalent.

## Features

* Takes a binary number from the user
* Processes each binary digit
* Converts it into decimal
* Displays the decimal result

## Technology Used

* C

## Concepts Used

* Variables
* While loop
* Modulus operator
* Arithmetic operations

## Sample Output

```text
Enter a binary number: 11001
Decimal: 25
```
